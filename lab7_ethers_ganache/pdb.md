# Lab 7 – Local Ethereum with Ethers.js

## 0. One-time setup (start here if you only copy-pasted the code)

### Prerequisites
| Need | Check with | If missing |
|---|---|---|
| Node.js 18, 20 or 22 (we used 20.19) | `node --version` | install the **LTS** from nodejs.org (Hardhat 2.x does not support odd/very new versions well) |
| npm (ships with Node) | `npm --version` | reinstall Node |
| Internet, once | - | the first compile downloads the Solidity compiler (see "Cache" below) |

### Create the project from scratch (only if you are NOT cloning the repo)
```
mkdir lab7_ethers_ganache
cd lab7_ethers_ganache
npm init -y
npm install --save-dev hardhat@2.22.17 @nomicfoundation/hardhat-ethers@3 ethers@6 --legacy-peer-deps
mkdir contracts scripts
```
Then create these files (copy-paste from this repo):
- `contracts/Token.sol` - the Solidity contract
- `scripts/lab7.js` - the script that deploys and tests
- `hardhat.config.js` - must contain:
```js
require("@nomicfoundation/hardhat-ethers");
module.exports = {
  solidity: "0.8.20",
  networks: { localnode: { url: "http://127.0.0.1:8545" } },
};
```
(`hardhat-ethers` is the plugin that adds `ethers` to Hardhat; `solidity` is the compiler version and must match `pragma solidity ^0.8.20;` in the contract.)

### If you cloned the repo instead
```
cd lab7_ethers_ganache
npm install --legacy-peer-deps
```
`package.json` already lists the dependencies. This creates `node_modules/` (not stored in git).

### Cache and generated folders (what appears and why)
- `node_modules/` - downloaded libraries.
- **Solidity compiler cache** - on the first `npx hardhat compile`, Hardhat downloads `solc 0.8.20` once into a global cache (Windows: `%LOCALAPPDATA%\hardhat-nodejs\Cache`, Linux: `~/.cache/hardhat-nodejs`, macOS: `~/Library/Caches/hardhat-nodejs`). Later compiles are offline and fast. No internet on exam day? Run one compile beforehand.
- `artifacts/` - compiled output (ABI + bytecode) used by scripts. `cache/` - Hardhat's incremental-compile bookkeeping. Both are regenerated by `npx hardhat compile`; safe to delete. **After editing a `.sol` file, always recompile.**

### Common errors
| Error | Fix |
|---|---|
| `ERESOLVE unable to resolve dependency tree` | add `--legacy-peer-deps` |
| `npx : File ...npx.ps1 cannot be loaded ... running scripts is disabled` (PowerShell) | run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` once, or use Git Bash / cmd |
| `HH1` (not inside a Hardhat project) | you are in the wrong folder - `cd` into the lab folder containing `hardhat.config.js` |
| `Cannot find module 'ethers'` / `hardhat` | `npm install --legacy-peer-deps` in this folder |
| `HH501` / `HH502` (compiler download failed) | no internet; connect once and rerun compile |
| `ENOENT artifacts/...json` | you forgot `npx hardhat compile` |

### Lab 7 extras
- You need **two terminals** open in this folder: one keeps `npx hardhat node` running (do not close it), the other runs `node scripts/lab7.js`.
- Port **8545** must be free. If `hardhat node` says the address is in use, find the process (`netstat -ano | findstr 8545` on Windows) and stop it, or run the node on another port: `npx hardhat node --port 8546` and set `RPC_URL=http://127.0.0.1:8546` for the script.
- Restarting `hardhat node` resets the chain to block 0 (fresh 10,000 ETH accounts). Compile first so `artifacts/` exists - `lab7.js` reads the token ABI from it.
- Setting env vars: Git Bash/Mac/Linux `VALUE=3 TO_INDEX=2 node scripts/lab7.js`; PowerShell `$env:VALUE=3; $env:TO_INDEX=2; node scripts/lab7.js`; cmd `set VALUE=3 && set TO_INDEX=2 && node scripts/lab7.js`.
- If the exam gives you Ganache instead: install it (`npm i -g ganache`), run `ganache`, and the same script works (default port 8545; the old Ganache GUI uses 7545, so set `RPC_URL`).

## How to run
Requires Node.js. This lab has its own `package.json`; install once with `npm install --legacy-peer-deps`. Ganache is deprecated, so `hardhat node` is used as the local RPC endpoint (same role).

Terminal 1 – start the local node:
```
cd lab7_ethers_ganache
npx hardhat compile
npx hardhat node
```

Terminal 2 – run the script:
```
cd lab7_ethers_ganache
node scripts/lab7.js
```

Task 4 (change account or value) – use environment variables:
```
VALUE=3 TO_INDEX=2 node scripts/lab7.js        # Git Bash
$env:VALUE=3; $env:TO_INDEX=2; node scripts/lab7.js   # PowerShell
```
`RPC_URL` can point to another endpoint. A saved run is in `lab7.output.txt`.

## Files and key components

**`scripts/lab7.js`** (plain ethers v6, no Hardhat runtime)
- Connects with `JsonRpcProvider`, prints chain ID, block number, and the first 5 accounts with balances (Task 1).
- Sends an Ether transfer from account 0 to account `TO_INDEX` (Task 2a).
- `printReceipt()` – prints hash, from, to, block, status, gas used, gas price, fee, value (Task 3).
- Receiver balance is read at the receipt's block and the block before it, which gives the exact change.
- Deploys the token, calls `transfer(receiver, 250)`, decodes the `Transfer` event and shows both balances (Task 2b).
- Final section sends an over-balance token transfer to show the revert reason (Task 4).

**`contracts/Token.sol`** – minimal ERC-20-like `SimpleToken`: `balanceOf`, `transfer` (reverts with "Insufficient token balance"), `Transfer` event.

**`package.json`** – this lab's own dependencies (Hardhat, ethers) and npm scripts (`npm run compile`, `npm start`, `npm run node`).

**`hardhat.config.js`** – Solidity 0.8.20; compiling creates `artifacts/`, which the script reads for the ABI and bytecode.

**`lab7.output.txt`** – saved output.
